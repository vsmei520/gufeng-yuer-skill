# 曾美团队·育儿国风穿越

基于 MCP 协议的育儿国风短视频创作助手，支持 OAuth 一键授权。

## 🚀 快速开始

### 第一步：添加插件市场

1. 打开 GPT 插件市场
2. 点击 **添加插件市场**
3. 输入仓库地址：
   ```
   https://github.com/vsmei520/gufeng-yuer-skill
   ```
4. 点击 **添加市场**

### 第二步：安装插件并授权

1. 在插件市场找到 **曾美团队-育儿国风穿越**
2. 点击右上角 **+ 安装插件**
3. **自动跳转到授权页面**
4. 输入手机号和授权码（从管理员处获取）
5. 点击"激活"
6. 授权成功后自动返回

✅ **安装完成！**

### 第三步：开始使用

在对话中输入：
```
启动曾美团队·育儿国风穿越，帮我生成一个古今对话短剧
```

## 💡 授权说明

- **OAuth 自动授权**：安装插件时自动跳转授权页面
- **一机一码**：每个授权码只能激活一次，绑定一台设备
- **支持多种授权**：月度/季度/年度/终身

## ❓ 常见问题

**Q: 授权码从哪里获取？**
联系管理员购买授权码。

**Q: 可以换设备吗？**
可以，联系管理员解绑后重新激活。

**Q: 忘记是否激活了？**
联系管理员查询你的授权状态。
