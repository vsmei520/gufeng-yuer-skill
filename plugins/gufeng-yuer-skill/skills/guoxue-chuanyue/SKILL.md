# 曾美团队·育儿国风穿越

这是曾美团队的远程授权 Skill 入口。

## 重要说明

**本插件不包含核心 Skill 规则。所有规则存储在远程服务器，通过授权后才能访问。**

## 使用流程

1. **首次使用**：调用任一远程工作流工具，Codex 会自动打开 OAuth 授权页；输入手机号和兑换码。
2. **完成授权**：浏览器完成授权后返回 Codex，MCP 令牌由 OAuth 自动管理。
3. **生成内容**：授权验证通过后，调用远程工作流工具生成古今对话短剧内容。

## 授权码获取

请联系管理员获取授权码。管理后台仅供管理员使用。

## 推荐启动词

首次使用：

```text
启动曾美团队·育儿国风穿越，帮我生成一个古今对话短剧。

选题：孩子不爱吃饭怎么办

初步构思：现代妈妈为孩子不吃饭焦虑，穿越回古代见到孟母，孟母分享古人育儿智慧，现代妈妈恍然大悟回到现实应用。
```

已完成授权后：

```text
@曾美团队-育儿国风穿越 生成一个关于"孩子沉迷手机"的古今对话短剧

选题：孩子沉迷手机

构思：现代父母为孩子玩手机头疼，穿越见王阳明，王阳明用"知行合一"理念启发教育方式，父母回到现代找到解决方案。
```

## 注意事项

- 核心 Skill 规则不在本地，无法查看或修改
- 授权码绑定设备，不可转让
- 每个用户默认绑定一台设备；换电脑时请联系管理员解绑
- 核心工作流从远程服务器按需读取，创作对话仍由本地 Codex 执行
- OAuth 令牌由 Codex 管理，无需手工复制或配置

## 生成流程

本 Skill 采用八阶段确认式工作流：

1. **阶段一**：钩子分析 + 典故取材
2. **阶段二**：结构设计 + 人物档案 + 时长精算
3. **阶段三**：四列脚本
4. **阶段四**：场景图 + 人物设定图 + 角色定位图提示词
5. **阶段五**：六列分镜表 + 10秒分割方案
6. **阶段六**：Seedance 分段提示词
7. **阶段七**：封面提示词（3:4 + 4:3）
8. **阶段八**：发布标题 + 标签 + 知识点清单

每个阶段输出后需要确认才能进入下一阶段。

## 技术规格

- **视频时长**：10秒段版本（单段10秒）
- **画幅比例**：16:9 横屏
- **台词占比**：90-95%
- **提示词上限**：1950字
- **语言**：全中文
- **BGM**：禁止（只用现场同期声）

## 常见问题

**Q: 如何获取授权码？**  
A: 请联系曾美团队管理员，或访问管理后台 https://guoxue.073955.com/admin

**Q: 可以在多台电脑使用吗？**  
A: 默认一个手机号只绑定一台设备。如需更换电脑，请联系管理员解绑后在新设备重新完成 OAuth 授权。

**Q: 如何检查授权状态？**  
A: 重新调用远程工作流工具即可。授权过期或失效时，Codex 会重新发起 OAuth 授权。

**Q: 核心规则在哪里？**  
A: 核心 Skill 规则存储在远程服务器，本地插件不包含规则明文，这是为了保护知识产权。
