# 曾美团队·育儿国风穿越

这是 Codex 插件市场仓库。插件通过远程 MCP 服务读取受授权保护的国学穿越工作流，本仓库不包含核心规则正文。

## 安装

1. 在 Codex 插件市场添加本仓库地址：

```text
https://github.com/vsmei520/gufeng-yuer-skill
```

2. 安装“曾美团队-育儿国风穿越”。
3. 首次调用国学穿越工具时，Codex 会自动打开 OAuth 授权页。
4. 输入手机号和管理员提供的兑换码，授权完成后回到 Codex。

## 说明

- 不需要手工复制 Client ID、Client Secret 或访问令牌。
- 核心 workflow 存储在服务器端。
- 默认一个用户绑定一台设备，需要换设备时请联系管理员解绑。
